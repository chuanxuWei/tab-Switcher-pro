# App icon

Generated using the built-in image_gen tool, then resized with macOS sips and packaged with iconutil. No external API key or generated-image runtime dependency.

Prompt:

> Use case: logo-brand. Create one polished macOS application icon for Tab Switcher Pro, a browser tab switcher with a rose-pink selection highlight. Square 1024x1024 icon asset, genuinely transparent outside a softly rounded square app tile. Inside an ivory frosted-glass tile, two overlapping browser-tab cards with a small elegant bidirectional switching arrow, front card outlined in deep rose pink. Subtle premium dimensional material, crisp silhouette, generous inset, legible at 32 pixels. Straight-on view, centered, no lettering, no watermark, no Chrome or Arc trademark, no surrounding scene. Deliver a single finished icon.

`AppIcon.png` is the source. Run `scripts/icon.sh` to regenerate `AppIcon.icns`.
